# 2026 ANU Festival

2026 안양대학교 축제에서 사용할 주문 관리 웹 서비스입니다.

## 프로젝트 소개

축제 부스의 주문 접수 및 관리 과정을 웹으로 처리하기 위한 서비스입니다.

고객은 웹을 통해 메뉴를 확인하고 주문할 수 있으며,
관리자는 접수된 주문과 주문 상태를 관리할 수 있습니다.
